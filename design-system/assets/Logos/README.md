# Logos

- `fork-mark-ink.svg`: the Fork mark, whole, in `ink` (#111111). For light grounds where inline SVG can't go: email, social cards, documents. On the site the mark is inline SVG (ForkMark), which cuts.
- `fork-mark-cut-ink.svg`: the mark cut, ink halves, the slash pink to blue (#C9338A to #5B8EF0) as everywhere the mark appears. For one still picture that should show the cut (a social card, a poster).
- `fork-mark-paper.svg`: the mark, whole, in `paper` (#f7f7f4), for dark grounds and `issue` fills.
- `neta-mark-paper.png`: the Neta DAO mark, as supplied (251×192, transparent), for the footer at 34px tall on `paper`, linking to netadao.org. Never redraw, recolour or crop it.
